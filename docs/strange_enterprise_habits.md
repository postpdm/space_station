# Strange enterprise habits

## User pseudo name

You may have noticed that an alias is created within the `User` model.

Use this specific alias when displaying various statistics, rankings, product analytics, and so on; you never know how a user might react to their name appearing in potentially sensitive reports, or whether their privacy and rights regarding personal data might be compromised.
